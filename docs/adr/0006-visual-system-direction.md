# ADR 0006: Dark Graphite Liquid Glass Visual System

## Status

Accepted.

## Context

Antrum previously documented a warm paper pixel direction. The product direction is now dark graphite, native macOS, and Liquid Glass focused.

## Decision

Keep the dark graphite local-machine design. Prefer native system buttons and controls. Use Liquid Glass surfaces for meaningful hierarchy and platform-native depth. Use spectral waveform color only for live audio, dictation, recording, and meeting-detection activity.

## Consequences

- `DESIGN.md` and `design/tokens.json` must describe the dark graphite system.
- Warm paper pixel language is deprecated.
- New UI work should use semantic tokens and native macOS controls first.
- Custom glass treatments require a documented product reason.
